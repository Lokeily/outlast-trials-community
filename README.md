# 逃生试炼社区

《逃生：试炼》(The Outlast Trials) 中文玩家共建攻略小站——复生配装、装备图鉴、新手培养方案、新闻资讯与社区讨论，一站直达。

🌐 **在线访问：** https://lokeily.github.io/outlast-trials-community/

---

## 关于本站

《逃生：试炼》是一款强调四人合作与潜行生存的长线恐怖游戏，系统复杂、赛季持续更新。但中文圈长期缺少一个集中且持续维护的攻略据点——零散的帖子很快随版本过时，新人在高压试验里反复踩坑，老玩家想查配装也只能东拼西凑。

**我们建这个站，就是为了补上这块空白。**

- **能帮到你什么**
  - 新手：照着培养路线与避坑指南，从建号到稳定通关少走弯路；
  - 老玩家：随时查阅配装与装备图鉴，跟进每个赛季的更新与活动；
  - 所有人：在社区讨论里交流心得、互助答疑，无需注册即可留言。
- **我们希望成为什么**
  - 一个由玩家持续维护、紧跟版本、让每一个中文玩家都能信赖并愿意回来的《逃生：试炼》社区。

这里的内容只围绕「真正对玩家有用」——不堆砌、不注水：红框即推荐，避坑即实战，并随每个赛季一同迭代。

## 网站特色

### 🎯 配装攻略
- **复生方案**：红框 / 👍 标注社区推荐项，三大类各 3×3 九宫格直接抄作业
- **装备图鉴**：按核心 / 新手 / 老玩家推荐分类 + 处方按等级筛选，点徽章也能筛选
- **新手小贴士**：四阶段培养路线 + 贴吧老玩家实战经验 + 可折叠 FAQ

### 🔄 自动化功能
- **活动倒计时**：新闻页的献血活动与 Twitch Drops 每天自动更新剩余天数，到期后自动隐藏
- **背景渐进加载**：先显占位图、主图加载完成后再渐显，首屏更顺滑
- **懒加载评论**：评论按需加载，不拖慢首屏

### 🎨 视觉设计
- 全站官方暗黑血红主题（玻璃拟态 + 微交互 + 跑马灯边框）
- Steam 官方高清宣传画虚化蒙版背景（暗角 + 氛围绕光）
- 移动端动效自动降级，尊重系统的「减少动态效果」设置

## 技术栈

| 项目 | 说明 |
|------|------|
| **架构** | 纯静态多页站，每个页面独立 HTML，零构建步骤 |
| **样式** | 单一 CSS 文件 `assets/css/style.css`，CSS 变量驱动主题 |
| **脚本** | 单一 JS 文件 `assets/js/site.js`，零依赖（除评论组件） |
| **评论** | Twikoo（Netlify + MongoDB Atlas 免费后端），国内可用 |
| **托管** | GitHub Pages（主分支自动部署） |
| **图标** | 游戏内真实图标（WebP/PNG 透明底），外链到官方 Wiki |
